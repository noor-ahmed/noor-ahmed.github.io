# Noor Ahmed Biswas — GitHub Pages Portfolio

A static portfolio website ready for GitHub Pages. No build tools are required.

## Included

- `index.html` — complete portfolio
- `assets/css/style.css` — responsive styling
- `assets/js/main.js` — mobile navigation and current year
- `assets/files/Noor-Ahmed-Biswas-CV.pdf` — CV download
- `404.html` — fallback page
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload **all files and folders in this package** to the repository root. `index.html` must remain at the root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **Branch: `main`** and **Folder: `/ (root)`**, then click **Save**.
7. Your project site will use a URL similar to:
   `https://YOUR-USERNAME.github.io/portfolio/`

If the repository itself is named `YOUR-USERNAME.github.io`, the URL will instead be:
`https://YOUR-USERNAME.github.io/`

## Customize

- Main content: edit `index.html`.
- Colors/layout: edit `assets/css/style.css`.
- Replace the CV: overwrite `assets/files/Noor-Ahmed-Biswas-CV.pdf` using the same filename.
- LinkedIn URL currently points to `https://www.linkedin.com/in/nahmed-bd/`.

## Troubleshooting “There isn't a GitHub Pages site here”

Check that:

- `index.html` is in the selected Pages folder.
- GitHub Pages is enabled under **Settings → Pages**.
- The branch is `main` and folder is `/ (root)`.
- You opened the exact Pages URL shown in GitHub Settings after deployment.
- For a project repository, the repository name is included in the URL.
